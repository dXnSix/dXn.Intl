## [0.1.2] - 2026-11-09

### Documentation
- Point the install snippets at v0.1.1
- Document compact numbers, units, relative times, lists, names, sorting and ranges

### Features
- *(number)* Format numbers in compact notation
- *(unit)* Format amounts of units of measure
- *(relative-time)* Format times relative to now
- *(list)* Join lists with the locale's words
- *(display-names)* Name languages, regions, scripts and locales
- *(collation)* Compare and sort text in the locale's order
- *(datetime)* Format ranges of dates and times of day
